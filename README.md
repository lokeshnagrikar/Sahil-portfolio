# 🎬 Sahil Anil Kamdi — Cinematic Portfolio Website

An Awwwards-winning personal portfolio website for **Sahil Anil Kamdi**, Lead Video Editor & Motion Graphics Specialist based in Gondia, Maharashtra, India.

Built with **Next.js 15**, **Tailwind CSS**, **GSAP ScrollTrigger**, **Lenis Smooth Scroll**, and **Web Audio API**.

---

## ✨ Features

- **Cinematic Darkroom Bootloader:** Real-time frame timecode boot sequence (`00:00:00:00`).
- **Interactive Hero Carousel:** Real studio photography background carousel with 3D mouse parallax tilt.
- **Inside the Workspace (About):** High-contrast editorial narrative and 5-step post-production pipeline.
- **Interactive Color Science Scrubber:** Pixel-perfect Before & After color grading slider.
- **Screening Room (Portfolio Showcase):** 3D perspective cards, category filters, scrub-on-hover previews, and full-screen cinema modal player with embedded 16:9 YouTube features and 9:16 vertical Shorts.
- **Creative Arsenal (Toolkit):** Interactive software proficiency bars (*Premiere Pro, After Effects, DaVinci Resolve, Photoshop, CapCut*).
- **Specialized Services:** 6 creator service cards with deliverables and quote triggers.
- **Final Export (Inquiry Brief Form):** Media Encoder render progress form with INR (₹) budget options, WhatsApp/Email triggers, and downloadable resume.
- **Audio Synthesizer & Cinema Mode:** Built-in Web Audio API sound effects synthesizer, Anamorphic 2.39:1 Cinema Mode, and Rule-of-Thirds Grid overlay.

---

## 🛠️ Tech Stack

- **Framework:** Next.js 15 (App Router, React 19)
- **Styling:** Tailwind CSS, Glassmorphism, Custom CSS Variables
- **Animations:** GSAP 3 (ScrollTrigger), Framer Motion
- **Smooth Scroll:** Lenis (`@studio-freight/lenis`)
- **Audio SFX:** Web Audio API Synthesizer (zero external MP3 dependencies)
- **Typography:** Google Fonts (`Inter` & `JetBrains Mono`)
- **Icons:** Lucide React

## 🚀 Quick Start (Local Setup)

1. **Clone the repository:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/sahil-kamdi-portfolio.git
   cd sahil-kamdi-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Open `http://localhost:3000` to view the website.
